## Master Icon List

11 unique icons required across all 6 product cards.

| Icon Name | What It Represents | Suggested Style |
|---|---|---|
| `icon-torque` | Output torque / rotational force | Circular arrow (rotation symbol) |
| `icon-weight` | Gate/door weight capacity | Scale or downward weight arrow |
| `icon-speed` | Speed in m/s or °/s | Speedometer dial |
| `icon-temperature` | Operating temperature range | Thermometer |
| `icon-length` | Gate or arm length | Horizontal double-headed arrow with ruler |
| `icon-wireless` | Bluetooth + WiFi connectivity | WiFi signal bars |
| `icon-certified` | CE certification | Shield with checkmark |
| `icon-concealed` | Concealed floor-mount installation | Arrow pointing into floor |
| `icon-noise` | Running noise level in dB | Sound wave or speaker |
| `icon-load` | Door/gate load capacity | Door with downward arrow |
| `icon-cycles` | Life cycle count | Circular refresh or loop arrow |

> Note: `icon-weight` and `icon-load` can share one icon to reduce the set to 10 if the designer prefers.
